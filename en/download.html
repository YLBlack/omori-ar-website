HOW TO INSTALL

ANDROID

  1. Download the APK using the button above.
  2. When your device asks you to allow installing from an unknown source, accept.
  3. Open the file, install it, then launch the game.

PC

  1. You need your own copy of the game on Steam. This translation is a mod that installs on top of it; it does not contain the game.
  2. Install the OneLoader mod loader by following the instructions on its page.
  3. Unzip the translation and copy the Omori AR folder into OMORI\www\mods\ inside the game folder.
  4. Launch the game and enable "Omori AR" from the mods menu.
