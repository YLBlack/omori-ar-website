## 📌 عن المشروع (About)

هذا المستودع يحتوي على الشفرة المصدرية (Source Code) للموقع الإلكتروني الخاص بـ **مشروع تعريب لعبة OMORI**. يهدف الموقع إلى إتاحة منصة سهلة وسريعة للاعبين لاستعراض تفاصيل التعريب، تحميل التعريب للكمبيوتر (وأجهزة الأندرويد إن وُجدت)، متابعة التحديثات، ومعرفة كيفية تثبيت المود وشخصيات القائمين على التعريب.

---

## 🚀 المميزات (Features)

- 🎨 **تصميم مخصص:** واجهة تعكس طابع وبيئة لعبة OMORI (White Space / Headspace).
- 📱 **متوافق مع كل الأجهزة:** تجربة متصفح سلسة ومستجيبة (Responsive) للكمبيوتر والهواتف الذكية.
- 📥 **روابط تحميل مباشرة:** الوصول إلى أحدث إصدارات مود التعريب وشرح خطوات التثبيت.
- 🌐 **دعم كامل للغة العربية (RTL):** محاذاة وتنسيق بصري متكامل للغة العربية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML5 & CSS3** - الهيكل البنائي والتنسيقات البصرية.
- **JavaScript** - التفاعلات والوظائف الديناميكية.
- **GitHub Pages / Vercel / Netlify** - الاستضافة المباشرة للموقع.
